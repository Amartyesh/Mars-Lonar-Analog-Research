# Data

This directory contains documentation related to the datasets used in the Lonar-Jezero comparative research project.

## Data Sources

### Lonar Crater
- Satellite: Sentinel-2
- Product: Level-2A Surface Reflectance
- Data type: Bottom-of-Atmosphere (BOA) reflectance
- Selected bands: B02, B03, B04, B05, B06, B07, B08, B11, B12
- Acquisition date: 12 March 2023

### Jezero Crater, Mars
- Mission: Mars Reconnaissance Orbiter (MRO)
- Instrument: Compact Reconnaissance Imaging Spectrometer for Mars (CRISM)
- Product: MTRDR
- Product ID: HRL000040FF_07_IF183J_MTR3
- Acquisition date: 29 January 2007

### Spectral Reference Libraries
- USGS Spectral Library
- Sentinel-2 resampled spectral reference library
- CRISM AREF spectral reference library

## Data Availability

Original satellite datasets are available from their respective official repositories.

Large raw satellite files are not stored in this GitHub repository. 
This directory is intended for dataset documentation and source information.
