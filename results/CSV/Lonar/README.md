# Lonar Crater - CSV Results

This directory contains the spectral analysis outputs generated from Sentinel-2 Level-2A imagery of Lonar Crater, India.

## Files

- Lonar_Median_Spectrum.csv
- SAM_Threshold_Comparison.csv
- SAM_Quality_Statistics.csv
- Mineral_Candidate_Distribution.csv

These files document reflectance characteristics, Spectral Angle Mapper classification thresholds, classification quality, and mineral candidate distribution.
