# CSV Results

This directory contains tabular outputs generated during the spectral and geospatial analysis.

Expected result files include:

- Lonar_Median_Spectrum.csv
- Lonar_Jezero_Comparative_Spectra.csv
- Jezero_SAM_Similarity_Matrix.csv
- Jezero_ROI_SAM_Results.csv
- Jezero_Mineral_Class_Statistics.csv
- Jezero_Equal_Band_Validation.csv
- Integrated_Project_Summary.csv

## Description

These files contain:

- Spectral reflectance measurements
- Region of Interest (ROI) spectral summaries
- Spectral Angle Mapper (SAM) similarity results
- Constrained spectral classification statistics
- Cross-environment spectral comparisons
- Equal-band validation results

The CSV files are intended to support reproducibility, interpretation, and further statistical analysis.
