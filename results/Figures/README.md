# Figures

This directory contains visual outputs generated during the research.

Expected figures include:

- Jezero_Final_Mineral_Map.png
- Jezero_Final_SAM_Matrix.png
- Lonar spectral classification maps
- Comparative Lonar-Jezero spectral plots
- ROI spectral plots

## Purpose

The figures illustrate:

- Spatial patterns in spectral classification
- Spectral similarity between observed and reference spectra
- Regional spectral variations across Jezero ROIs
- Comparative spectral characteristics of Lonar and Jezero

All figures should be interpreted in the context of the methodological limitations described in the research report.
